# UyFox News - Windows ئۈستەلئۈستى پىروگراممىسى قوللانمىسى (Windows Desktop Application Guide)

بۇ ھۆججەت **UyFox News** نى نورمال Windows پىروگراممىسى (`.exe`) شەكلىدە قانداق ئىجرا قىلىش ۋە ئورنىتىشنى چۈشەندۈرىدۇ.

---

## 1. نېمە ئۈچۈن Windows پىروگراممىسى؟
UyFox News پەقەت كىچىك Chrome قىستۇرمىسى (375px) بولۇپلا قالماي، تولۇق ئېكرانلىق **نورمال Windows 10/11 ئۈستەلئۈستى پىروگراممىسى** ھېسابلىنىدۇ:
- **كۆپ بۆلەكتە راھەت ئوقۇش (Multi-Pane Desktop Interface):** چوڭ ئېكراندا خەۋەرلەر، ماقالە تەھلىلى ۋە جۇغراپىيىلىك سىياسەت كۆرۈنۈشى بىرلەشتۈرۈلگەن.
- **3D يەرشارى ۋە يىپەك يولى خەرىتىسى (Three.js WebGL):** سىياسىي تۈگۈنلەرنى 3 ئۆلچەملىك كۆرۈش.
- **توردىن بىۋاسىتە ئىزدەش (Google Search Grounding - Gemini 3.8 Flash):** ھەقىقىي مەنبەلىك ئەڭ يېڭى خەۋەرلەرنى قاڭقىتىپ ئېلىش.
- **Windows قورال بالدىقى (System Tray Integration):** خىزمەت جەريانىدا ئارقا سۇپىدا ئۈن-تىنسىز ئىشلەش.
- **Windows قاچىلاش بولىقى (NSIS Installer & Portable .exe):** بىرلا چەككەندە قاچىلاش.

---

## 2. ئىجرا قىلىش ۋە قاچىلاشنىڭ 2 ئاسان ئۇسۇلى

### ئۇسۇل 1: Windows PWA ئارقىلىق 1 سېكۇنتتا قاچىلاش (تەۋسىيە)
1. Edge ياكى Chrome توركۆرگۈچتە UyFox News نى ئېچىڭ.
2. ئوڭ ئۈستىدىكى تىزىملىكتىن ياكى تېلېفون/كومپيۇتېر قورال بالدىقىدىن **«Windows غا پىروگرامما قىلىپ قاچىلاش (Install UyFox News)»** نى چېكىڭ.
3. پىروگرامما تۈگەل توركۆرگۈچتىن ئايرىلىپ، مۇستەقىل بىر Windows دېرىزىسىدە، ئۈستەلئۈستى تېزلەتمە بەلگىسى بىلەن ئىجرا بولىدۇ.

### ئۇسۇل 2: Electron ئارقىلىق .exe بولاق تۈزۈش
ئەگەر ئۆزىڭىز خاس مۇستەقىل `.exe` ياسىماقچى بولسىڭىز:
```bash
# 1. تۈر قىسقۇچىغا كىرىڭ
cd desktop

# 2. كېرەكلىك Electron كۈتۈپخانىلىرىنى ئورنىتىڭ
npm install -D electron electron-builder

# 3. دەرھال سىناق كۆزنىكىنى ئېچىش
npm start

# 4. Windows قاچىلىغۇچ .exe نى ھاسىللاش
npm run pack:win
```
بۇ مەشغۇلاتتىن كېيىن `dist/` ئىچىدە `UyFox-News-Setup-1.0.0.exe` نامىدا مۇستەقىل Windows قاچىلاش ھۆججىتى چىقىدۇ.

---

## 3. بىخەتەرلىك ۋە نۆل تېلېمېتىرىيە (Zero-Telemetry)
Windows نۇسخىسىدىمۇ بارلىق تەڭشەك ۋە ماقالىلەر پۈتۈنلەي ئۆز كومپيۇتېرىڭىزدا مەخپىي ساقلىنىدۇ؛ ھېچقانداق سانلىق مەلۇمات خىتاي سېرۋېرلىرىغا ياكى نازارەت سىستېمىلىرىغا يوللانمايدۇ.
